ОСНОВНЫЕ УЛУЧШЕНИЯ ВЕРСИИ (10/10):
========================================================================
1. АВТОНОМНОСТЬ И ЧЕТКОСТЬ: Все иконки в HTML встроены как чистые пиксельные SVG. Никаких внешних ссылок и никаких эмодзи!
2. ЧЕТКОЕ РАЗДЕЛЕНИЕ O2 И ТЕМПЕРАТУРЫ: Шкалы O2 (45%) и ТЕМП (-14°C) разнесены на отдельные аккуратные индикаторы.
3. IN-WORLD ПРОГРЕСС РАЗРУШЕНИЯ: Полоса разрушения блока (70x6 px, 75%) перенесена из угла HUD прямо к курсору в центре экрана.
4. ЛАКОНИЧНЫЕ ЗАГОЛОВКИ: Короткие названия вкладок (ИНВЕНТАРЬ, КРАФТ, СУНДУК, КАРТА, ЖУРНАЛ, НАСТРОЙКИ, КОНСОЛЬ).
5. GODOT 4 ANCHOR LAYOUT: Поддержка адаптивной вёрстки на основе контейнеров MarginContainer, HBoxContainer, VBoxContainer.
6. НОЛЬ ГРАДИЕНТОВ: Только сплошные заливки из утверждённой палитры игры.
7. АВТОФОКУС В КОНСОЛИ: Мгновенный возврат фокуса в поле ввода после отправки команды.

========================================================================
РУКОВОДСТВО ПО ИМПОРТУ В GODOT 4:
========================================================================
1. Текстуры: При импорте ashenroot_spritesheet.png или файлов из assets/panels/ установите Filter = Nearest (Pixel Perfect).
2. NinePatchRect (9-Slice): Для панелей и кнопок укажите patch_margin_left = 4, patch_margin_right = 4, patch_margin_top = 4, patch_margin_bottom = 4.
3. Состояния кнопок: Используйте button_normal.png, button_hover.png, button_pressed.png, button_disabled.png из папки assets/panels/. Текст локализации рендерится шрифтом поверх спрайта.
4. Цветовая палитра Hex:
   - Тон фона: #0B0E12, #141A1E, #20272A
   - Рамки: #4B5855, #71837B
   - Текст основной: #DDD5BC, вторичный: #9C9A89
   - Активный / свечение: #82C7B1
   - Редкий предмет: #B79CFF
   - Предупреждение: #DB8A55, опасность: #C95D5D
   - Здоровье: #B23838, стамина: #5E8F6A, мана: #53AEBF.

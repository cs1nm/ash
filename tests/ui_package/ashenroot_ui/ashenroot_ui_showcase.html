АРХИТЕКТУРА ИНТЕРФЕЙСА ДЛЯ GODOT 4 (УЧТЕНЫ ВСЕ ЗАМЕЧАНИЯ):

1. Упрощённый HUD (Тихая разведка против динамических угроз): В базовом состоянии HUD показывает только HP, Стамину, компактный Квикбар и активные дебаффы. Босс-бар, O2/Температура и предупреждение Левиафана привязаны через сигналы к событиям и появляются динамически (проверьте кнопку-переключатель вверху экрана).
2. Адаптивность через Godot Anchors и Containers: Вместо общего сжатия 1920×1080 элементы привязаны к краям: MarginContainer с PRESET_TOP_LEFT (бары здоровья), PRESET_TOP_RIGHT (мини-карта), PRESET_BOTTOM_CENTER (квикбар в HBoxContainer). При смене разрешения экрана 1080p -> 720p отступы и привязки сохраняются.
3. Локальные шрифты без внешних зависимостей: В проекте Godot размещайте шрифты в res://ui/fonts/press_start_2p.ttf и res://ui/fonts/jetbrains_mono.ttf. В CSS реализован надёжный локальный fallback.
4. Строгое отсутствие градиентов: Все фоны, полосы здоровья, панели и кнопки используют 100% сплошные заливки из палитры игры.
5. Логика консоли: При выполнении команды фокус ввода мгновенно возвращается в поле (решен UX-баг с потерей фокуса).
